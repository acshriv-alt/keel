# Examples

Filled-in Keel files from a fictional courier-notification product called
Parcel, so the shape is concrete. Names and numbers are invented; the
structure is exactly what lands in a real repo.

- `state.md`: a `keel/STATE.md` mid-project.
- `brief.md`: an `F-0007` brief that passed Gate 1 with changes.
- `council-gate1.md`: the Gate 1 verdict for that brief.
- `decision.md`: a decision record produced by that verdict.
- `audit-entry.md`: the audit entry for the push that shipped it.
- `adopters/BLOODKONNECT.md`: a real adoption plan for an existing project
  with its own tracking docs, scrubbed of internal numbers. Shows how to map
  old files to Keel without a migration.
