# Examples

Filled-in Scantling files from a fictional courier-notification product called
Parcel, so the shape is concrete. Names and numbers are invented; the
structure is exactly what lands in a real repo.

- `state.md`: a `scantling/STATE.md` mid-project.
- `brief.md`: an `F-0007` brief that passed Gate 1 with changes.
- `evidence.md`: the `EVIDENCE.md` written before that Gate 1, showing what a
  useful evidence sheet looks like: every line a command and its output, the
  constraints quoted in full because the voices cannot open the file, and the
  two gaps the chair filled after the first pass.
- `council-gate1.md`: the Gate 1 verdict for that brief.
- `decision.md`: a decision record produced by that verdict.
- `audit-entry.md`: the audit entry for the push that shipped it, with the
  declared tier, the reality check and the process ratio.
- `adopters/BLOODKONNECT.md`: a real adoption plan for an existing project
  with its own tracking docs, scrubbed of internal numbers, plus what the
  project measured after one working session and what it changed in Scantling.
